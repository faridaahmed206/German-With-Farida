🇩🇪 Lesson 4 - Modalverben

الأفعال الناقصة في اللغة الألمانية

🏠 العودة إلى A2

📚 أولًا: ما هي Modalverben؟

الـ Modalverben هي أفعال بنستخدمها عشان نعبر عن القدرة أو الضرورة أو السماح أو الرغبة وغيرها.

أهم قاعدة:

عند استخدام Modalverb، يتم تصريف الـ Modalverb، بينما الفعل الأساسي يذهب إلى نهاية الجملة في المصدر Infinitiv.
Ich kann Deutsch sprechen.
أنا أستطيع التحدث بالألمانية.

⭐ أهم Modalverben

الفعل المعنى
können يستطيع / يقدر
müssen يجب / لازم
dürfen مسموح له
wollen يريد
sollen ينبغي / من المفترض
mögen يحب / يفضل
möchten يود / يرغب

🔵 können = يستطيع / يقدر

الضمير التصريف
ichkann
dukannst
er / sie / eskann
wirkönnen
ihrkönnt
sie / Siekönnen
Ich kann Deutsch sprechen.
أنا أستطيع التحدث بالألمانية.
Wir können schwimmen.
نحن نستطيع السباحة.

🔴 müssen = يجب / لازم

الضمير التصريف
ichmuss
dumusst
er / sie / esmuss
wirmüssen
ihrmüsst
sie / Siemüssen
Ich muss heute lernen.
يجب أن أذاكر اليوم.

🟢 dürfen = مسموح له

الضمير التصريف
ichdarf
dudarfst
er / sie / esdarf
wirdürfen
ihrdürft
sie / Siedürfen
Du darfst nicht rauchen.
غير مسموح لك بالتدخين.

🟣 wollen = يريد

الضمير التصريف
ichwill
duwillst
er / sie / eswill
wirwollen
ihrwollt
sie / Siewollen
Ich will Deutsch lernen.
أريد أن أتعلم الألمانية.

🟠 sollen = ينبغي / من المفترض

الضمير التصريف
ichsoll
dusollst
er / sie / essoll
wirsollen
ihrsollt
sie / Siesollen
Du sollst mehr lernen.
ينبغي أن تذاكر أكثر.

💗 mögen = يحب / يفضل

الضمير التصريف
ichmag
dumagst
er / sie / esmag
wirmögen
ihrmögt
sie / Siemögen
Ich mag Pizza.
أنا أحب البيتزا.

💙 möchten = يود / يرغب

möchten بنستخدمها بطريقة مهذبة لما نكون عايزين حاجة.

الضمير التصريف
ichmöchte
dumöchtest
er / sie / esmöchte
wirmöchten
ihrmöchtet
sie / Siemöchten
Ich möchte einen Tee.
أود كوب شاي.
Möchtest du einen Kaffee?
هل تود قهوة؟
Wir möchten Deutsch lernen.
نود تعلم الألمانية.

📌 ترتيب الجملة

مع Modalverben:

الفاعل + Modalverb المصرف + باقي الجملة + الفعل الأساسي في المصدر
Ich kann Deutsch sprechen.
Ich = الفاعل
kann = Modalverb
sprechen = الفعل الأساسي في آخر الجملة
Wir müssen heute lernen.
يجب أن نذاكر اليوم.

❓ الأسئلة مع Modalverben

Kannst du Deutsch sprechen?
هل تستطيع التحدث بالألمانية؟
Musst du heute lernen?
هل يجب أن تذاكر اليوم؟
Willst du mitkommen?
هل تريد أن تأتي معنا؟

❌ النفي مع Modalverben

Ich kann nicht schwimmen.
أنا لا أستطيع السباحة.
Ich will nicht gehen.
أنا لا أريد الذهاب.
Du darfst hier nicht parken.
غير مسموح لك بركن السيارة هنا.
