📘 What is Passiv?

نستخدم Passiv عندما يكون التركيز على الفعل أو الشيء الذي حدث، وليس على الشخص الذي قام بالفعل.

Der Mann repariert das Auto.
الرجل يصلح السيارة.
Das Auto wird repariert.
يتم إصلاح السيارة.

🔄 Aktiv und Passiv

Aktiv – المبني للمعلوم

Der Lehrer erklärt die Grammatik.
المعلم يشرح القواعد.

Passiv – المبني للمجهول

Die Grammatik wird erklärt.
يتم شرح القواعد.

⏰ Passiv im Präsens

في المضارع نستخدم:

werden + Partizip II
werden + التصريف الثالث للفعل
Das Auto wird repariert.
يتم إصلاح السيارة.
Das Essen wird gekocht.
يتم طبخ الطعام.
Die Tür wird geöffnet.
يتم فتح الباب.

📝 تصريف werden

  • ich → werde
  • du → wirst
  • er/sie/es → wird
  • wir → werden
  • ihr → werdet
  • sie/Sie → werden
Das Haus wird gebaut.
يتم بناء المنزل.

🔤 Partizip II

في الـ Passiv نستخدم Partizip II.

reparieren → repariert
يصلح → تم إصلاحه
schreiben → geschrieben
يكتب → مكتوب
bauen → gebaut
يبني → مبني

👤 استخدام von

إذا أردنا ذكر الشخص الذي قام بالفعل، نستخدم von + Dativ.

Das Auto wird von dem Mann repariert.
يتم إصلاح السيارة بواسطة الرجل.
Das Buch wird von der Lehrerin gelesen.
يتم قراءة الكتاب بواسطة المعلمة.

⏳ Passiv في الماضي البسيط

في الماضي البسيط نستخدم:

wurde + Partizip II
wurde + التصريف الثالث
Das Haus wurde gebaut.
تم بناء المنزل.
Das Auto wurde repariert.
تم إصلاح السيارة.

📌 Zusammenfassung

  • Präsens: werden + Partizip II
  • Präteritum: wurde + Partizip II
  • von + Dativ: لذكر الشخص الذي قام بالفعل
