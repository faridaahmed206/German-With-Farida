📚 ما هو Passiv؟

نستخدم Passiv عندما يكون التركيز على الفعل أو الشيء الذي حدث، وليس على الشخص الذي قام بالفعل.

Der Lehrer erklärt die Grammatik.
المعلم يشرح القواعد.
Die Grammatik wird erklärt.
يتم شرح القواعد.

1️⃣ Aktiv und Passiv

Aktiv Passiv
Der Schüler schreibt den Brief. Der Brief wird geschrieben.
Die Mutter kocht das Essen. Das Essen wird gekocht.
Der Mechaniker repariert das Auto. Das Auto wird repariert.

2️⃣ Passiv im Präsens

في زمن المضارع نستخدم:

werden + Partizip II
Das Auto wird repariert.
يتم إصلاح السيارة.
Das Essen wird gekocht.
يتم طهي الطعام.

3️⃣ تصريف werden

الضمير werden
ich werde
du wirst
er / sie / es wird
wir werden
ihr werdet
sie / Sie werden

4️⃣ Partizip II

الفعل الأساسي في Passiv يأتي في آخر الجملة بصيغة Partizip II.

Infinitiv Partizip II المعنى
machen gemacht يفعل
schreiben geschrieben يكتب
reparieren repariert يصلح
bauen gebaut يبني

5️⃣ استخدام von

لو عايزين نذكر الشخص الذي قام بالفعل، يمكن استخدام von + Dativ.

Der Brief wird von dem Schüler geschrieben.
يتم كتابة الخطاب بواسطة الطالب.
Das Auto wird von dem Mechaniker repariert.
يتم إصلاح السيارة بواسطة الميكانيكي.

6️⃣ Passiv في الماضي البسيط

في Präteritum Passiv نستخدم:

wurde / wurden + Partizip II
Das Haus wurde gebaut.
تم بناء المنزل.
Die Häuser wurden gebaut.
تم بناء المنازل.

📝 ملخص سريع

  • Präsens Passiv: werden + Partizip II
  • Präteritum Passiv: wurde / wurden + Partizip II
  • Partizip II يأتي في نهاية الجملة.
  • von + Dativ يستخدم لذكر الشخص الذي قام بالفعل.
  • Passiv يركز على الحدث أو الشيء الذي وقع عليه الفعل.
