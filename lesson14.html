🇩🇪 الدرس الرابع عشر

mein / dein / sein / ihr

الملكية في اللغة الألمانية

🎯 أهداف الدرس

  • فهم معنى mein / dein / sein / ihr.
  • قول: كتابي، كتابك، كتابه، كتابها.
  • التفرقة بين الملكية مع المذكر والمؤنث والمحايد.
  • استخدام كلمات الملكية في جمل بسيطة.
  • السؤال عن صاحب الشيء باستخدام Wem gehört...?

📌 1. يعني إيه كلمات الملكية؟

كلمات الملكية بتوضح مين صاحب الشيء.

mein Buch

= كتابي

dein Buch

= كتابك

sein Buch

= كتابه

ihr Buch

= كتابها

📚 2. أهم كلمات الملكية

الألماني المعنى
mein ـي / بتاعي
dein ـك / بتاعك
sein ـه / بتاعه
ihr ـها / بتاعها

mein Bruder

= أخي

dein Bruder

= أخوك

sein Bruder

= أخوه

ihr Bruder

= أخوها

📊 5. جدول سريع

مذكر / محايد مؤنث
أنا mein meine
أنت dein deine
هو sein seine
هي ihr ihre
⭐ ركز:

mein Bruder
لكن:
meine Schwester

لأن Bruder = der
و Schwester = die

✏️ 6. أمثلة مهمة

Das ist mein Vater.

= هذا أبي.

Das ist meine Mutter.

= هذه أمي.

Das ist dein Buch.

= هذا كتابك.

Das ist deine Tasche.

= هذه حقيبتك.

Das ist sein Bruder.

= هذا أخوه.

Das ist seine Schwester.

= هذه أخته.

Das ist ihr Handy.

= هذا هاتفها.

Das ist ihre Uhr.

= هذه ساعتُها.

❓ 7. Wem gehört...?

Wem gehört das Buch?

فيم جيهورت داس بوخ؟

= الكتاب ده بتاع مين؟

Das ist mein Buch.
= ده كتابي.

أو:

Das ist dein Buch.
= ده كتابك.

🆕 3 كلمات جديدة

gehören
النطق: جيهِـورن
المعنى: يخص / يكون ملكًا لـ
wem
النطق: فيم
المعنى: لمن؟ / بتاع مين؟
Besitzer
النطق: بِزيتسَر
المعنى: المالك / صاحب الشيء

📝 التدريب

1. Das ist ___ Bruder.
"هذا أخي."

2. Das ist ___ Tasche.
"هذه حقيبتها."

3. اكتب بالألماني: هذا كتابك.

🗣️ محادثة قصيرة

A: Wem gehört das Buch?
الكتاب ده بتاع مين؟

B: Das ist mein Buch.
ده كتابي.

A: Und wem gehört die Tasche?
والحقيبة دي بتاعة مين؟

B: Das ist ihre Tasche.
دي حقيبتها.

A: Ist das dein Handy?
هل ده هاتفك؟

B: Ja, das ist mein Handy.
أيوه، ده هاتفي.
