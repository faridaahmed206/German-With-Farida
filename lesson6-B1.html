📚 Adjektivdeklination – نهايات الصفات

في اللغة الألمانية، الصفة Adjektiv يمكن أن تتغير نهايتها حسب نوع الاسم والحالة الإعرابية.

يعني بدل ما نقول دائمًا: gut ممكن تتحول إلى: gute / guten / gutem / guter / gutes.

ein guter Mann
رجل جيد
eine gute Frau
امرأة جيدة
ein gutes Kind
طفل جيد

🧩 لماذا تتغير نهاية الصفة؟

لأن نهاية الصفة تساعدنا على معرفة:

  • الجنس: مذكر / مؤنث / محايد / جمع
  • الحالة: Nominativ / Akkusativ / Dativ / Genitiv
  • نوع الأداة الموجودة قبل الاسم
⭐ في B1 لازم تبدأ تركز على نهاية الصفة، لأنها مهمة جدًا لتكوين الجملة بشكل صحيح.

1️⃣ بعد أداة التعريف Der / Die / Das

مع أدوات التعريف مثل: der, die, das, die تكون نهايات الصفات غالبًا سهلة.

الحالة مذكر مؤنث محايد جمع
Nominativ der gute Mann die gute Frau das gute Kind die guten Kinder
Akkusativ den guten Mann die gute Frau das gute Kind die guten Kinder
Dativ dem guten Mann der guten Frau dem guten Kind den guten Kindern
Genitiv des guten Mannes der guten Frau des guten Kindes der guten Kinder
💡 احفظ دول كويس:

der gute Mann
die gute Frau
das gute Kind
die guten Kinder

2️⃣ بعد أداة التنكير ein / eine

هنا الصفة أحيانًا تحتاج إلى نهاية توضح الجنس والحالة.

الحالة مذكر مؤنث محايد
Nominativ ein guter Mann eine gute Frau ein gutes Kind
Akkusativ einen guten Mann eine gute Frau ein gutes Kind
Dativ einem guten Mann einer guten Frau einem guten Kind
Genitiv eines guten Mannes einer guten Frau eines guten Kindes

3️⃣ بدون أداة تعريف

عندما لا توجد أداة قبل الاسم، تكون نهاية الصفة مهمة جدًا.

الحالة مذكر مؤنث محايد جمع
Nominativ guter Mann gute Frau gutes Kind gute Kinder
Akkusativ guten Mann gute Frau gutes Kind gute Kinder
Dativ gutem Mann guter Frau gutem Kind guten Kindern
Genitiv guten Mannes guter Frau guten Kindes guter Kinder

🔑 طريقة سهلة للتفكير

Der / Die / Das → غالبًا -e / -en

Ein / Eine → ممكن -er / -e / -es / -en

بدون أداة → الصفة تحمل النهاية المهمة.

📝 أمثلة مهمة

Der alte Mann wohnt hier.
الرجل العجوز يعيش هنا.
Ich sehe den alten Mann.
أنا أرى الرجل العجوز.
Ich helfe dem alten Mann.
أنا أساعد الرجل العجوز.
Eine schöne Stadt liegt am Meer.
توجد مدينة جميلة على البحر.
Ich kaufe ein neues Auto.
أشتري سيارة جديدة.
Mit einem neuen Auto fahre ich zur Arbeit.
أذهب إلى العمل بسيارة جديدة.

⚠️ قبل اختيار نهاية الصفة

  1. حدد الحالة: Nominativ / Akkusativ / Dativ / Genitiv
  2. حدد الجنس: مذكر / مؤنث / محايد / جمع
  3. شوف الأداة: der / ein / بدون أداة
⭐ مثال:

Ich sehe den kleinen Hund.

den = Akkusativ مذكر
لذلك نقول: kleinen

📌 الخلاصة

أداة + صفة + اسم

النهاية تتغير حسب:
الحالة + الجنس + نوع الأداة
